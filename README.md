# Pontuação — Tribo de Judá (FJU)

Dashboard da pontuação da Tribo de Judá, com memória de cálculo semana a semana.

**Acesse:** https://thallesdaniel.github.io/pontuacao_juda/

## Como atualizar todo mês

Todos os dados ficam no objeto `DADOS`, no topo do script do `index.html`:

1. Abra o `index.html` e localize `const DADOS`.
2. Adicione a nova semana/mês com as atividades (quantidade × valor unitário).
3. Faça o commit na branch `main`. O GitHub Pages republica sozinho em 1–2 minutos.

A tabela de critérios de pontuação também fica dentro de `DADOS`.
